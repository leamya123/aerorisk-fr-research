# Data provenance and access

`raw/` and `processed/` directories deliberately contain no simulated values pretending to be observational data. Cite exact source URL, access date, variable unit and transformations when data is collected.

Do not commit: university-licensed WRDS/Cirium datasets, copyrighted PDFs without redistribution permission, personal contact information, credentials, or private interview notes. Track restricted inputs in a local private data manifest; publish only code and legally shareable derived results.
