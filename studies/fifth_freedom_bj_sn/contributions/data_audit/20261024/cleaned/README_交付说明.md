## 四、缺失值说明

空字符串表示尚未填写或尚未证实。

空字符串不等于：

- false
- 0
- 未获得授权
- 未实际运营

NA 表示不适用。

前端不得将未知值直接转换为否定结论。

## 五、来源核验

25 条来源记录中：

- 21 条历史检查记录返回 HTTP 200/206
- BJ06 返回 HTTP 500
- UE01、BJ03、CN01 检查状态不明确

全部 25 条历史 URL 检查记录缺少精确检查时间和方法。

历史 HTTP 状态不能证明网址当前有效，
也不能证明来源内容已经完成独立核实。

## 六、政策事件日期

11 条政策事件中：

- 5 条具有精确日期
- 6 条只有时间锚点

不得人为补齐缺失日期。

## 七、候选航线

18 条数据是候选航线审计记录，
不是 18 条已获第五航权授权的航线。

R03 和 R07 具有相同标准化行程，
但属于不同审计记录，予以保留。

个案授权和实际运营证据仍存在缺口。

不得据此计算第五航权实际授权率。

## 八、法律证据

法律条文的英文内容为分析性转述，
不是独立认证译文。

法律生效日期和个别条款解释
仍需要进一步复核。

## 九、网页接入

建议优先使用 evidence.cleaned.json。

正式替换网页数据前，需要检查：

1. JSON 是否正常加载
2. 来源 ID 是否正确关联
3. 空值是否正确显示
4. 18 条航线是否被正确解释为候选审计记录
5. 新增字段是否影响原有图表

## 十、结论

已完成数据整理、主键检查、
内部来源引用检查及 JSON 导出。

现有数据可以用于研究展示和网页开发，
但不能视为全部外部事实已经独立证实。
