## 必须补充的口径说明

1. **金融版本差异**：工作簿中的2024Q4—2026Q1区域贷款利率下降25基点，对应旧季度公报版本（6.97%→6.72%）。当前主面板选定版本为6.97%→6.70%，下降27基点。两者不可无版本标识混用；答辩主图采用主面板的27基点。不得把版本修订解释成经济变化。
2. 2025Q1科特迪瓦、塞内加尔跨版本差异为44、114基点。针对一阶差分的敏感性分析，还应排除受滞后值影响的2025Q2；仅排除2025Q1不够。年度报告与季度报告涉及的2025年UEMOA均值6.69%/6.73%口径差异继续保留为待核问题。
3. 金融工作簿覆盖年度面板中的三个地区/国家序列，不是全部七个序列。Air Côte d’Ivoire早年图示数据存在取整，不能称为逐年审计财报全覆盖。旧租赁情景模拟仍不是真实租赁价格；利率、融资成本与利润的并列描述不构成因果识别。
4. 清洗JSON中的`"true"`/`"false"`是字符串，不能使用普通布尔真值转换。`canonical_itinerary_key`只是文本归一化键，不能作为已核实航程或自动删重依据；R03/R07同键也不等于可以删除一条。
5. 25条来源中的历史HTTP状态有21条200/206、1条500、3条未知；均缺少逐次请求准确时间和方法。打包时间不是链接访问时间，本次不能称为“全部链接现时可达”。
6. 9条法条的生效日期尚缺，不等于法律未生效；官方文件、官方声称、承运人报告、正式批准与实际运营必须分层。JSON中`scope B`仅描述法律子研究收缩范围，不改变全项目“制度开放＋金融约束”的综合方向。
